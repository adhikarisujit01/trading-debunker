# Trading Debunker

I test viral trading strategies with real backtests, so you don't have to lose money learning they don't work.

YouTube: Trading Debunker - @TradingDebunker

## How it works

Each video has its own folder:
- `video-01-macd-tradinglab/` - I Tested TradingLab's BEST MACD Strategy [86% Win Rate]
- `video-02-.../` - next test goes here

Each folder has:
- The Pine Script (.pine) - paste into TradingView Pine Editor, Add to chart
- A README with the exact test setup and results

## How to run a test

1. Open TradingView, SPY
2. Pine Editor (bottom) > paste the .pine file > Add to chart
3. Strategy Tester (bottom) > Overview
4. Check: Total trades, Win rate, Total PnL, Profit factor, Max drawdown

No cherry-picking. All trades counted, with commission.
